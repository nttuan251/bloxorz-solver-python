How to play

Roll the 1×1×2 block until it stands upright in the glowing hole. Falling off the edge restarts the level.

  • Floor tileA normal, solid tile. Holds the block in any orientation.
  • Empty cell (void)No tile. If any part of the block ends up over it, the block falls.
  • Fragile tileCracks if the block stands upright on it. Lying down is fine.
  • BridgeOpens and closes when a switch is pressed.
  • Soft switchActivated when any part of the block presses it, standing or lying.
  • Heavy switchActivated only when the block is standing on it.
  • Split switchActivated only when the block is standing on it: splits it into two 1×1×1 cubes. Space switches which cube you move; they merge again on adjacent tiles.
  • Goal holeStand the block upright on it to fall in and win. Lying across it does not win.

The solver panel runs BFS, DFS, UCS or A* in Python and replays the answer. Coloured tiles show where the search looked: the further along the colour bar under "Show explored tiles", the more states it expanded there.
